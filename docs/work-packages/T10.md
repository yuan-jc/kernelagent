# T10：状态机与预算恢复

## 契约

- 状态：IN_PROGRESS（2026-09-13 契约冻结）。依赖 T05（ACCEPTED）、T08（ACCEPTED）、T09（ACCEPTED）。
- 对应设计章节：§7（自动执行状态机与故障恢复）、§12（预算记账）。
- 目标行为：可恢复的实验状态机——动作（评测/计时/确认/修复）以追加事件日志驱动；预算先预留后结算，超预算拒绝启动新动作；中断重启后未完成动作显式标记 interrupted 并可重跑，绝不假成功；cancel 在动作边界生效；每个动作（含修复/autotune 类）都计费。
- 事件日志：workspace 下 JSONL 追加（action_started / action_finished / action_interrupted / budget_reserved / budget_settled / experiment_done），事件含动作名、输入 hash、预算数、结果引用。

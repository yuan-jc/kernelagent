# T07：正式计时协议

## 契约

- 状态：ACCEPTED（2026-09-13，目标 Ubuntu + NVIDIA 真机验收）。依赖 T05（ACCEPTED）。
- 对应设计章节：§9.3（计时契约）、§9.4（统计单位）。
- 环境与边界：复用 ADR-0001 容器边界 + ADR-0002 评测镜像（image ID `sha256:b598274a…`）；评测对象经 T04 隔离执行；NCU/profiling 时间不得进入正式结果（结果 schema 带 `source: cuda_event` 标记）。
- 目标行为：对同一协议下的 reference(eager)/compile/candidate 输出**原始批样本**（非单一均值）；A/A 给出噪声与自助置信区间；异步/漏同步反例被检出。
- 计时目标：预热后的 operator 入口 GPU 延迟（CUDA event，输入驻留 GPU）；JIT/autotune/IO 不在热窗口但单列；协议参数显式固定并可序列化。
- 本包不包含：晋升规则与 δ 判定（T09）、sanitizer/扩展正确性（T06）、NCU 取证（T15）。

## TimingProtocol（v1，固定字段）

`warmup_iters`、`num_batches`、`iters_per_batch`、`input_rotation`（rotate/固定）、`stream_policy`（current-stream 事件对 + 批末设备级 synchronize）、`cache_state`（warm）、`statistics`（逐批原始样本 + 批内均值/最小值）、`outlier_rule`（不丢弃，原样报告）、`device`、`seed`。冷缓存批次单列（batch0 先于统计窗口时显式标注）。环境状态（时钟/温度/利用率，nvidia-smi 实测值）前后各记录一次，不声称锁频。

# T03：目标 Ubuntu/NVIDIA 环境验收

状态：READY_FOR_ACCEPTANCE；GPU NOT_RUN。依赖 T00/T08；设计 §10、§12。

目标：在最终使用的 Ubuntu + NVIDIA 环境确认设备身份、CUDA 驱动、小型 kernel 写读与工具状态。Windows/WSL 历史探测不替代目标验收。没有“必须更换显卡”的既定结论。

## 输入与命令

固定当前提交（工作区差异另存），运行已有 `gpu-probe-v1`。具体安装步骤见 [Ubuntu 指南](../UBUNTU.md)。

```bash
uv run --locked kernelagent check --output artifacts/ubuntu-cpu
uv run --locked kernelagent probe --target native --output artifacts/ubuntu/probe --evidence-root artifacts/ubuntu/evidence
```

## 必需观察

| 项目 | 验收标准 | 当前目标机器状态 |
|---|---|---|
| CPU | 必需回归通过；Linux 仅 Windows 专用用例可有解释地跳过 | NOT_RUN |
| 身份与报告 | GPU 型号/UUID、驱动、系统/Python、协议、源码提交可追溯；报告符合 schemas/gpu-probe.schema.json | NOT_RUN |
| 驱动与 kernel | cuda_driver_api、cuda_kernel_launch 均 pass；真实 kernel 写 42 并回读匹配，CUresult trace 可查 | NOT_RUN |
| 工具 | nvcc/ncu 与可选 Python 包的可用性、版本、错误如实报告；缺口对 T04/T05/T15 的影响明确 | NOT_RUN |
| 证据 | 原始报告、日志与退出码保存；报告 artifact hash 可校验，EvidenceStore audit 健康 | NOT_RUN |
| 负例 | 缺工具为 unavailable，错误/超时为 fail；子进程崩溃不使整个报告消失，不把 mock 当 GPU | CPU 回归覆盖；目标运行另记 |

exit 0 不代表 GPU 通过。NCU 版本查询不是 profiling 验收；真实 `.ncu-rep` 属 T15。若环境/驱动/权限失败，保存观察与最小复现，不先归因为虚拟化或硬件故障。

验收后更新 task board、当前交接与证据索引（提交、环境、输入/协议、命令、退出码、日志 hash、检查状态），转 ACCEPTED，再进入 T04。本包不包含容器、worker 服务、计时或优化算法。

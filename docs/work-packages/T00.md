## 实现说明

`kernelagent check` 面向可信项目测试，不执行不可信生成 kernel，不是 sandbox。pytest 返回 0 仍须存在至少一个实际通过的 testcase，且没有 failure/error。每次运行写唯一目录，保存 stdout/stderr/JUnit/hash 与版本化 JSON，避免旧报告被误认为本次成功。混合 skip 明确计数，由上层工作包决定是否允许；全 skip 拒绝。

报告会含本地机器路径，不自动纳入公开源码；本地 artifacts 与第三方研究原始快照被 Git 忽略。公开仓库保存本项目代码、设计、来源清单和检索脚本。

## 晋升规则 v1（实现前冻结）

- 硬约束：correctness ∧ compiled ∧ 资源未超限 ∧ guard 通过，任一失败即对应 `reject_*` 终态，永不晋升。
- 确认比较：`S = mean(T_incumbent批次) / mean(T_candidate批次)` 的 95% bootstrap 区间（重采样单位=batch，seed 显式）；区间下界 > 1 + δ（δ=0.02 开发初值，显式记录）才 `promote`；区间含 1+δ 或样本不足 → `retain_incumbent`（不确定不晋升）。
- 聚合：`fast_p = (1/N) Σ 1[correct_i ∧ T_ref,i / T_cand,i > p]`（阈值严格大于，以实现为准并记录）；failed/unsupported 单列并报告 attempted/eligible coverage，分母不变。
- δ、置信水平、批次结构、seed 都是决策记录的必填字段。

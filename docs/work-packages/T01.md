## 结论

### 2026-09-12 审查修复

- 修复 frozen dataclass 接受 `list` 或错误子对象导致的伪不可变状态；所有 tuple 字段及嵌套 domain 对象现在在构造边界严格校验，允许空串的 `notes`/`guard`/`origin` 也拒绝非字符串。
- 反序列化现在拒绝 envelope、顶层对象和嵌套对象的未知字段，并要求集合字段使用 JSON array，避免 `strides` 被静默丢弃或字符串被隐式拆成 tuple。
- 当前 CPU 证据：269 passed / 0 failed / 0 errors / 0 skipped；共享证据为 `docs/evidence/review-fixes-2026-09-12.json`。本节更新不覆盖上方历史验收记录。

- 是否满足本包全部必需检查：是。GPU = N/A、LIVE_MODEL = N/A（本包为离线契约层，不涉及硬件或模型执行）。
- 与设计的偏差及 ADR：设计 §5.4 草案把 `content_sha256` 写为 `Implementation` 构造字段；实现改为内容派生函数 `content_sha256()` / `implementation_id()`，避免"frozen 外壳内 hash 与内容不一致"的非法状态，语义与 §11.1 一致。草案自声明"接口草案不是已实现 SDK"，属实现期细化，不单列 ADR。补充决定：`implementation_id` 不含 operator_id/backend/parent_ids/origin（它们描述用法与出处而非构建物本体），测试锁定该边界。
- 仍未验证的范围：domain 对象与真实 KernelBench 数据的兼容性在 T02 用真实快照验证；序列化目前仅支持 12 类对象，后续包新增对象时扩展注册表并保持版本化。

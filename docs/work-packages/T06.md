# T06：增强正确性

## 契约

- 状态：ACCEPTED（2026-09-13，目标真机 GPU 验收）。依赖 T05（ACCEPTED）。
- 对应设计章节：§9.1（正确性层次）、§9.2（信任边界）；上游评分独立性保持（扩展赛道单列，ADR-0002）。
- 环境：复用 ADR-0001 容器边界 + ADR-0002 评测镜像（含 compute-sanitizer）。
- 目标行为：在 pinned 上游 evaluator 之外增加扩展正确性检查，全部单列报告，不混入 upstream_compatible 赛道；候选不能自证任何一项。
- 检查项（fixup correctness-pro v1）：
  1. `baseline`：候选输出 vs 参考输出 allclose（预条件）。
  2. `input_mutation`：候选调用前后输入张量逐字节比对。
  3. `constant_output`：两组不同随机输入的输出必须不同。
  4. `shape_dtype`：输出 shape/dtype 与参考一致。
  5. `tail_check`：逐元素差异分析 + 末尾区域专项比对（错尾反例）。
  6. `state_check`：A、B、A 序列调用，同输入两次结果必须一致且均正确（陈旧缓存检出）。
  7. `sanitizer`：compute-sanitizer memcheck 短调用；状态 pass / fail / not_run（工具缺失单独记，绝不记 pass）。
- 反例夹具：常量输出、原地改输入、错尾、陈旧状态、合法候选（Triton LayerNorm 复用）。
- 本包不包含：正式计时（T07 已含）、晋升（T09）、NCU（T15）。

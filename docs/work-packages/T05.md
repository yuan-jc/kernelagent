## 契约

- 状态：IN_PROGRESS（2026-09-13 开始实现）。依赖 T02（ACCEPTED）、T03（ACCEPTED）、T04（ACCEPTED）。
- 对应设计章节：§8.1、§9.1。
- 环境决策：[ADR-0002](../adr/0002-eval-image-and-protocol-references.md)（锁定评测镜像、`utils.py` 协议引用扩展、正确性-only 赛道）。
- 目标行为：pinned 上游 evaluator（`src/kernelbench/eval.py::eval_kernel_against_ref`）在 ADR-0001 容器边界内真实执行；控制端适配器不导入 torch，判定只从上游序列化结果派生。
- 问题类别（8GB 显存约束下选定，三类别 × 正反例 + compile 基线）：
  - l1 p001 方阵矩阵乘（matmul 类）
  - l1 p040 LayerNorm（归一化类）
  - l2 p001 Conv2d+ReLU+BiasAdd（融合卷积类）
- 本包不包含：正式计时协议（T07）、扩展正确性（T06）、性能排名/晋升（T09）。

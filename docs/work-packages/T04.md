# T04：可信 GPU worker

## 契约

- 状态：IN_PROGRESS（2026-09-13 开始实现）。依赖 T01（ACCEPTED）、T03（ACCEPTED）；T04a 提供进程机制基线，不替代本包。
- 对应设计章节：§7、§9.2、§12。
- 边界决策：[ADR-0001](../adr/0001-trusted-worker-container-boundary.md)（Docker + NVIDIA Container Toolkit/CDI；镜像按 digest 锁定；非 root、禁网、只读输入、tmpfs 输出、cgroup 限额、GPU 按 UUID 独占）。
- 目标行为：候选代码只能在容器边界内执行；可信父端掌握请求身份、reference、正确性规则与结果落盘；候选退出码/stdout/自写 JSON 不构成正确性或晋升。
- 修改范围：`src/kernelagent/worker/`（新增容器执行器）、`tests/test_container_worker.py`、`examples/container_gpu_smoke.py`、本卡片与文档。
- 本包不包含：KernelBench 原生 evaluator 对照（T05）、计时协议（T07）、搜索/方法生成/NCU 分析。

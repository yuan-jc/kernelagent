## 范围（Alpha 冻结）

- 单 problem：`kernelbench:l1:40`（KernelBench L1 P40 LayerNorm）；backend=`triton`；单 RTX 4060（按 CDI UUID 固定）。
- 产品入口：`kernelagent optimize|resume|status`；主循环顺序固定：
  `generate -> policy gate -> evaluate -> correctness_pro -> timing -> confirm -> persist`。
- 每个候选一个 orchestrator action；预算、恢复、中断标记全部来自 durable journal（T10 语义，含 Task 2 的 durable budget 重建）。

## 信任规则（ADR-0004）

- 候选不可信：AST policy 门（`inspect_candidate_policy`）在花费任何 GPU 之前拒绝篡改模式候选。
- Alpha 威胁模型：`candidate_trust=cooperative`、`adversarially_secure=false` 写入每份报告；champion 需人工审查。
- 失败反馈只含结构化类别 + 截断的编译错误尾部（≤800 字符），不含密钥/宿主路径/无限日志。

## 接口

- `OptimizationConfig`：problem/backend/model_id/base_url/max_candidates/max_repair_rounds/gpu_budget_seconds/token_budget/output/resume/snapshot_root/gpu_device。
- `optimize(config, *, generator=…, evaluate=…, correctness_pro=…, timing=…, confirm=…) -> OptimizationResult`：端口可注入（离线测试），CLI 走真实 T05/T06/T07/T09 适配器。
- 终态与退出码：`completed`=0、`no_improvement`=1、`budget_exhausted`=2、配置错误=3、`infra_error`=4。
- 密钥：仅控制端环境变量 `MODEL_PROVIDER_API_KEY`；缺失是显式配置错误，绝不回放冒充。

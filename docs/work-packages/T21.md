# T21：多 workload 与 dispatch

## 契约

- 状态：ACCEPTED（2026-09-13，目标真机 GPU 验收）。依赖 T06（ACCEPTED）、T09（ACCEPTED）、T13（ACCEPTED）。
- 对应设计章节：§4–5（任务粒度/workload）、§9.4（聚合与最差回退）。
- 目标行为：一个 dispatch 层为多 workload 任务选择实现：每条 guard（形状/布局/数据类型约束）实际执行检查，全部必测 workload 正确才可用；聚合按预固定权重，不允许只看获益形状；guard 失败或退化超阈 → 显式回退到参考实现（fallback），回退本身也要正确。
- 本包不包含：搜索（T16）、NCU（T15 已含）。

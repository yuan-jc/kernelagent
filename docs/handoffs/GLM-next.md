# GLM 后续开发要求

最终首用平台是 Ubuntu + NVIDIA GPU。Windows 用于可独立验证的 CPU 开发。遵循 `AGENTS.md`、设计文档、开发任务与验收计划，以及 `docs/handoffs/current.md`；本文件补充本轮审查后的交接边界。

## 下一项任务：复验 T03

先同步本仓库，核对当前提交、工作区和本轮修复证据 `docs/evidence/review-fixes-2026-09-12.json`。不要回退修复，也不要依据旧探测失败推断必须换显卡、Windows 是虚拟机或 WSL 不可用。

目标 Ubuntu + NVIDIA 环境可用时，在目标机器仓库根目录执行：

```bash
uv sync --locked
uv run --locked kernelagent check --output artifacts/t03-ubuntu-cpu
uv run --locked kernelagent probe --target native --output artifacts/t03-ubuntu --evidence-root artifacts/t03-ubuntu-evidence
```

保存每条命令的退出码和原始日志、报告 SHA-256、提交 SHA、未提交源码差异、Ubuntu/Python/驱动/CUDA 版本和 GPU 型号。核对报告 schema、各检查状态及真实 kernel 写入/读回 42 的证据。命令 exit 0 本身不够：工具缺失也可能返回成功退出，不能把 `unavailable` 当作通过。报告必须可入证据库并通过完整性检查。

T03 按原工作包的全部必需检查验收；后续 worker 所需工具缺失须逐项列出。NCU 版本可查询不等于 profiler 可运行，真实 profiling 保留到 T15。没有目标环境时，将目标 GPU 检查记为 NOT_RUN，保留精确命令与阻塞条件，不修改验收门槛，不用 mock 或 Windows GPU 运行替代 Ubuntu GPU 验收。

T03 经复核验收后才进入 T04。T04 首先只完成可信 worker 边界，按原卡片验收；不要一次跨到计时、搜索、模型生成或完整 agent。未获得目标环境时，仅推进用户指定、依赖满足的离线工作；如需拆包，先写清独立范围并保留父包验收条件。

## 每次只交付一个可复核的工作包

1. 编码前冻结目标行为、输入输出、允许修改文件、依赖证据、非目标，以及可执行验收命令。任务大小应能在一次开发窗口内交接。
2. 正例之外必须有能识别原缺陷的负例。测试不能只重复实现逻辑；mock 要验证真正的接口约束。CPU 测试必须隔离真实驱动、网络与模型调用，尤其注意 monkeypatch 不会自动传播到子进程。
3. 优先复用 KernelBench 和既有工具；禁止为过测修改上游清单、正确性容差、协议、统计分母或缩减真实验收。关键接口偏离记录 ADR。
4. 运行受影响检查和完整 CPU 验收、lint/格式检查；涉及安装分发时构建并在干净环境安装 wheel。修复引发新变更后重新验证相关检查。提交后的 CI 必须绑定本次提交；旧提交的绿色 CI 不证明新代码通过。
5. 回归必须守住：不可变对象与稳定哈希、JSON 严格类型/未知字段拒绝、证据损坏/缺失/元数据冲突拒绝、实验记录哈希验证、请求响应身份匹配、预算非整数/NaN 拒绝、探针失败隔离与资源清理。
6. 保存代码/输入/环境/协议身份、原始命令与退出码、测试通过/失败/跳过数量、日志和报告 hash。证据路径标明本地或 CI 可访问位置，不只写“全部通过”。不要提交凭据、虚拟环境、上游缓存或大体积运行目录。
7. 实现完成先交付 READY_FOR_ACCEPTANCE 和检查证据；交由独立审查确认后再更新 ACCEPTED。GPU/LIVE_MODEL 未执行必须 NOT_RUN，不能用单测数量、mock、skip 或自述替代。
8. 每包更新工作卡、task board 与 current handoff：已完成行为、失败与未执行项、已知限制、活动进程、恢复命令和下一步。额度将尽时先保存交接与可恢复状态，不能以额度为由虚报完成。

## 本轮修复仍保留的边界

- T01/T08/T12a 的 CPU 验证不等于 agent 已完成或 GPU 性能已验证。
- 存储当前约定单写入器，同一内容 hash 仅有一组索引元数据；不同 provenance 冲突明确报错。多 provenance 需求另行设计，不能静默覆盖。
- 内容 hash 用于完整性与身份绑定，不是抵御拥有整个存储写权限者的数字签名。候选与可信 evaluator 的权限隔离仍属于 T04 等后续工作。
- 模型回放约定请求与响应 model_id 精确匹配。后续真实提供方若返回解析后的模型版本，应显式设计并测试映射规则，不直接放宽校验。
- 历史探测失败报告仅保留观察事实；新环境结论必须来自修复后运行与必要的对照证据。
